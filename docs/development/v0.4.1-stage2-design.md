## 三、A1 — HV/CAV 子群拆分

### 3.1 vehicle_type_map

**来源**：`run_dir / "vehicle_type_map.json"` — 阶段 0 产物，`{"veh0": "CAV", "veh1": "HV", ...}`

**校验函数**（throw on error，调用者不忽略返回值）：

```python
def load_and_validate_type_map(run_dir: Path, spec: "RunSpec") -> dict[str, str]:
    path = run_dir / "vehicle_type_map.json"
    if not path.exists():
        raise FileNotFoundError(f"{path} missing")

    raw = path.read_text(encoding="utf-8")
    try:
        type_map = json.loads(raw)
    except json.JSONDecodeError as e:
        raise ValueError(f"vehicle_type_map.json: invalid JSON: {e}")
    if not isinstance(type_map, dict):
        raise ValueError("vehicle_type_map.json: top-level must be dict")

    if len(type_map) != spec.vehicle_count:
        raise ValueError(f"type_map: {len(type_map)} entries, expected {spec.vehicle_count}")

    cav_count = sum(1 for v in type_map.values() if v == "CAV")
    hv_count = spec.vehicle_count - cav_count
    if cav_count != (spec.cav_count or 0):
        raise ValueError(f"type_map: CAV count {cav_count} != spec.cav_count {spec.cav_count}")
    if hv_count != spec.hv_count:
        raise ValueError(f"type_map: HV count {hv_count} != spec.hv_count {spec.hv_count}")

    for vid, vt in type_map.items():
        if vt not in ("HV", "CAV"):
            raise ValueError(f"type_map: vehicle {vid} has unknown type '{vt}'")

    expected_ids = {f"veh{i}" for i in range(spec.vehicle_count)}
    actual_ids = set(type_map.keys())
    missing = expected_ids - actual_ids
    if missing:
        raise ValueError(f"type_map: missing keys {sorted(missing)}")
    extra = actual_ids - expected_ids
    if extra:
        raise ValueError(f"type_map: unexpected keys {sorted(extra)}")

    return type_map
```

### 6.1 Parser 契约

```python
def parse_fcd(
    fcd_path: str,
    type_map: dict[str, str],
    warmup_period: float = 600.0,
    thw_min_speed_mps: float = 0.1,
) -> dict:
    """
    流式解析 gzip/plain FCD XML，使用 ET.iterparse + (gzip.open as needed)。

    Returns:
        {
            "all": {"mean_thw_s": float, "median_thw_s": float, "p05_thw_s": float,
                    "thw_lt_1s_ratio": float, "valid_thw_sample_count": int,
                    "low_speed_excluded_count": int, "no_leader_count": int,
                    "self_leader_count": int, "parse_success": bool},
            "HV":  {同上},
            "CAV": {同上},
```

**follower 分类**：使用 `type_map[vehicle.id]` 作为权威分类（与其他 parser 一致）。
同时校验 FCD `type` 属性与 `type_map` 一致：若不一致 → `parse_success=False`。
`vehicle.id` 不在 `type_map` 中 → `parse_success=False`。
不存在“仍计入 all 但不入子群”的静默丢失路径。

**台账不变量**（闭合）：
- `all.valid_thw_sample_count == HV.valid_thw_sample_count + CAV.valid_thw_sample_count`
- 排除计数同理：`all.low_speed == HV.low_speed + CAV.low_speed`，等

```
流式解析阶段： 三个 array('d') (all_arr, hv_arr, cav_arr)
                每条记录同时 append 到 all 和子群 → 数据量 = 2 × 样本数
                0.1s × 120 veh × 3000s = 3.6M records
                all_arr: 3.6M × 8B = 28.8 MB
                hv_arr:  ~1.8M × 8B = 14.4 MB (典型 50/50)
                cav_arr: ~1.8M × 8B = 14.4 MB
                流式阶段峰值: 57.6 MB

计算阶段：     逐个 array 转换为 np.array → np.sort(in-place) → 计算 stats → del
                每个 array 转换 + 排序峰值: 28.8 MB（临时的 numpy 副本）
                计算阶段峰值: 57.6 + 28.8 = 86.4 MB

总体峰值:      86.4 MB (RSS 实测允许 < 200 MB)
```

**关键细节**：
- 每条 THW 样本同时进入 `all_arr` 和对应子群数组，因此总 double 数 ≈ 2 × 有效样本数（非 3×）
- `np.array(arr, dtype=np.float64)` 默认 copy=True → 创建副本
- 排序使用 `a.sort()`（in-place method，非 `np.sort(a)` 返回副本）
- all 统计直接从 `all_arr` 计算，**不拼接** HV+CAV 子数组

### 6.3 排除优先级

```python
# 每条 vehicle 记录的处理顺序：
# 1. time < warmup → skip
# 2. 解析 speed = float(veh.get("speed"))
#    → ValueError/TypeError 或 not isfinite → low_speed_excluded，进入台账
# 3. 解析 leaderGap = float(veh.get("leaderGap"))
#    → ValueError/TypeError 或 leaderGap <= 0 or not isfinite → no_leader
# 4. leaderID = veh.get("leaderID", "")
#    → leaderID == "" → no_leader
# 5. leaderID == vehicleID → self_leader
# 6. speed < thw_min_speed_mps → low_speed_excluded
# 7. thw = leaderGap / speed
#    → not isfinite(thw) → no_leader
# 8. → valid sample，加入数组
```

### 6.4 输出

subgroup 长表 `metric_family="headway"`，`group_dimension="vehicle_type"`。
不进入 core summary。
