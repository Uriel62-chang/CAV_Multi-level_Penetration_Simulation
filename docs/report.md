# 基于 SUMO 的 CAV 多级渗透率混合交通流多维评价仿真实验报告（v0.4.0）

> **实验版本**：v0.4.0
> **实验日期**：2026-07
> **仿真平台**：Eclipse SUMO 1.27.1
> **实验规模**：10,080 次仿真（4 场景 × 2 模型 × 21 渗透率 × 12 车辆数 × 5 车辆类型排列种子）

> **post3 说明**：本次修订不重跑 SUMO，保留既定实验输入与 raw XML；针对
> post2 发现的安全事件分子使用 `[600, 3600)`、edgeData 分母使用 `[0, 3600)`
> 的时间窗错配，从冻结 raw 数据统一按 `[600, 3600)` 重解析 SSM、performance
> 与 emissions，并据此更新派生数据、图表、结论和报告。

## 摘要

本实验基于 SUMO [1] 构建了包含四个分层场景（方形闭环、平滑闭环、双车道换道、合流瓶颈）的混合交通流仿真平台，在 IDM [2] 与 CACC [3] 两种 CAV 跟驰模型下，对 0% 至 100% 共 21 级请求 CAV 渗透率进行了系统性的批量仿真。实验从**观测流量、安全（TTC 冲突 [5]）、环保（CO₂ 排放）和效率（相对参考圈时差）**四个维度对仿真结果进行了多维评价。核心发现包括：（1）s2 全 CAV 运行点下，CACC 在测试网格内的最大观测流量为 7,128 veh/h，较 IDM 高 13.6%；该点位于车辆数上界，不构成真实容量峰值估计；（2）在 s3 全 CAV、高密度固定运行点，IDM 流量为 CACC 的 2.1 倍，相对参考圈时差约为其 1/3，普通 edge 排放强度和按普通 edge 里程归一化的 TTC 指标也更低；（3）TTC 冲突事件主要集中于具有急弯或合流约束的场景；（4）两种模型显式设置的 tau 均为 0.6s，因此观察差异不是由显式 tau 取值不同造成；模型专属默认参数及车辆级作用机制仍需进一步验证。

## 1. 实验背景

### 1.1 问题缘起

v0.2.0 在原始方形闭环路网（scenario_0）中观测到约 1,800 veh/h 的容量平台，IDM 与 CACC 在 100% CAV 条件下未呈现明显容量差异。v0.3.0 引入多场景框架后，在平滑闭环（scenario_1）高渗透率段观测到 CACC 容量高于 IDM（+8.6%）；双车道场景（scenario_2）的单位车道容量未达到单车道结果的严格两倍，差距约为 0~11%；合流瓶颈场景（scenario_3）相对 s2 的容量下降约为 43~77%，且 CACC 的表现随密度和渗透率出现明显变化。这些场景比较能够描述结果随几何和拓扑约束的变化，但具体车辆级机制仍需额外证据。

然而，v0.3.0 的评价体系局限于**单一容量维度**。单一通行能力指标无法完整评估跟驰模型的优劣——更高的通行能力可能以更高的安全风险、排放或延误为代价。

### 1.2 v0.4.0 的核心问题

> CAV 及其跟驰控制带来的容量收益，是否伴随着安全、环保或时间效率方面的代价？

v0.4.0 将评价体系从单一容量扩展为**容量 + 安全 + 环保 + 效率**四维，并引入 5 个车辆类型排列种子以观察结果对初始 CAV/HV 空间排列的敏感性；这些种子不是独立的 SUMO 随机重复。

### 1.3 证据与表述原则

本报告按证据强度区分三类内容：

1. **直接观测**：CSV 和聚合结果中可复核的流量、当前 TTC 归一化指标、排放和相对参考圈时差；
2. **场景比较**：在当前参数网格内，不同场景、模型和运行点之间的结果差异；
3. **机制假设**：对车辆级间距、加减速度、换道响应和扰动传播过程的解释。

前两类构成本报告的主要结论。第三类在缺少 FCD、THW 或 TraCI 轨迹验证时只
作为待检验解释，不写成已证实因果关系。“显著”一词仅在具有明确统计检验时
用于统计显著性；本报告的五个 seed 是车辆类型排列，不支持独立随机重复意义
下的显著性推断。

## 2. 实验设计

### 2.1 四场景分层框架

| 场景 | 边数 | 车道 | 几何特征 | 环路总长 | 自由流圈时 | 实验角色 |
|---|---|---|---|---|---|---|
| s0 | 4 | 1 | 90° 直角弯 | 2.0 km | 98.8s | 几何瓶颈对照 |
| s1 | 32 | 1 | ~11° 缓弯 | ~2.0 km | 60.3s | 纯跟驰基准 |
| s2 | 32 | 2 | 双车道 + LC2013 换道 | ~2.0 km | 60.6s | 无瓶颈多车道基准 |
| s3 | 32 | 2→1→2 | 125m 单车道瓶颈 (e15/e16) | ~2.0 km | 60.6s | 合流瓶颈场景 |

四个场景构成分层比较链：**几何弯曲度（s0 vs s1）→ 车道与横向自由度（s1 vs s2）→ 合流约束（s2 vs s3）**。该设计有助于定位结果差异出现在哪类场景变化中，但场景对照本身不等同于车辆级因果机制证明。

### 2.2 实验参数

| 参数 | 取值 | 数量 |
|---|---|---|
| CAV 跟驰模型 | IDM, CACC | 2 |
| 请求 CAV 渗透率 (requested pCAV) | 0.00, 0.05, ..., 1.00 | 21 |
| 车辆数 (vehN) | 10, 20, ..., 120 | 12 |
| 车辆类型排列种子 (seed) | 1, 2, 3, 4, 5 | 5 |
| **合计** | | **10,080 次仿真** |

这里的 `pCAV` 是请求渗透率，实际 CAV 数量按
`round(vehN × pCAV)` 取整，实际渗透率为 `CAV 数量 / vehN`。因此请求值与
实际值并不总是一致。最明显的是 `vehN=10`：21 个请求水平只能形成 11 种
实际车辆组成，例如请求 0.15、0.20 和 0.25 均生成 2 辆 CAV 和 8 辆 HV，
实际渗透率均为 0.20。这是已完成 v0.4.0 实验的已知设计缺陷。

全网格共有 2,400 个 run 的实际渗透率不等于请求值，其中 `vehN=10` 有
400 个 run 属于相同场景、模型和类型排列种子下的重复渗透率处理。正式结果
仍按请求 `pCAV` 分组，以保持已发布结果兼容性；这些重复水平不能解释为新的
独立渗透率处理。核心峰值和高密度比较使用 `vehN=60`、80 或 120，这些车辆数
可以精确实现 0.05 的渗透率步长，因此主要结论不受该离散化缺陷影响。

五个 seed 仅控制固定初始位置上的 CAV/HV 类型排列，不是五个独立的 SUMO
随机重复；尤其在 `pCAV=0` 和 `pCAV=1` 时，seed 不会产生不同的车辆类型排列。
各 run 先独立计算事件/里程等比率，随后对成功的车辆类型排列 run 作等权
算术平均和标准差；这里不是将五个 seed 的事件总数除以总暴露量的 pooled
ratio。因此这些统计量描述排列敏感性，不用于置信区间、显著性检验或独立
随机重复意义上的不确定性推断。

### 2.3 仿真配置

- 仿真时长：3,600 s，预热期 600 s
- 仿真步长：0.1 s
- 检测器频率：120 s（避免与 ~60s 单圈时间产生采样共振）
- HV 跟驰模型：Krauss [4]（tau=1.5s, minGap=2.5m, actionStepLength=1.0s）
- IDM/ACC/CACC 参数：统一 accel=3.0 m/s², decel=4.5 m/s², minGap=0.5m, actionStepLength=0.1s
- IDM tau=0.6s, CACC tau=0.6s（排除显式 tau 取值差异，但不隔离模型专属默认参数）
- 双车道场景启用 SUMO LC2013 换道模型 [6]
- SSM 配置：TTC 阈值 3.0s [7], DRAC 阈值 3.0 m/s² [8], trajectories=false（仅记录极值）
- 排放模型：HBEFA3/PC_G_EU4 [9]（HV 与 CAV 使用同一排放等级）

### 2.4 四维评价指标

| 维度 | 主指标 | 辅助指标 | 数据源 |
|---|---|---|---|
| **流量表现** | 流量 (veh/h)、测试网格内最大观测流量 | 检测断面速度、速度方差 | E1 检测器 |
| **安全** | 全路网 TTC 事件 / 1000 普通-edge veh-km | DRAC 极值、紧急制动次数、换道间隙 | SSM / stderr / lanechange |
| **环保** | 普通-edge CO₂ g/veh-km | NOx、PMx、燃油总量及强度 | edgeData emissions |
| **效率** | 平均相对参考圈时差 (s) | P95 参考差、圈时标准差、timeLoss | vehroute / edgeData performance |

post3 的所有归一化指标均使用 `[600, 3600)` 内的
`total_vehicle_km` 作为分母；performance、emissions、E1、SSM、紧急制动、
换道与圈时由此采用一致**时间窗口**。空间范围并不完全一致：历史 edgeData
排除了 internal edges，而 SSM 事件未作相同过滤。SSM 以 `minTTC@time` 和
`maxDRAC@time` 判断极值是否位于窗口内。0 与 NaN 严格区分：0 表示成功采集且无事件，NaN
表示数据源缺失或解析失败。

## 4. 实验结果

### 4.1 测试网格内最大观测流量

#### 4.1.1 各场景最大观测流量

| 场景 | IDM 最大观测流量 | @ pCAV, vehN | CACC 最大观测流量 | @ pCAV, vehN |
|---|---|---|---|---|
| s0（方形闭环）| 1,794 veh/h | 1.00, 60 | 1,856 veh/h | 1.00, 90 |
| s1（平滑单车道）| 3,475 veh/h | 1.00, 70 | 4,345 veh/h | 0.95, 90 |
| s2（双车道）| 6,276 veh/h | 1.00, 120 | **7,128 veh/h** | 1.00, 120 |
| s3（瓶颈）| 3,902 veh/h | 1.00, 80 | 3,564 veh/h | 1.00, 60 |

**测试网格内全局最大观测流量**为 s2 CACC 全 CAV 条件下的
7,128 veh/h。该值位于 `vehN=120` 的网格上界；由于没有更高车辆数下的下降段，
不能将其视为已经识别的真实容量峰值。

#### 4.1.2 场景间观测峰值变化

- **s0 → s1**：网格内观测峰值提升约 2.3×
- **s1 → s2**：双车道观测峰值约为单车道的 1.6~1.8×
- **s2 → s3**：网格内观测峰值下降约 45~50%，是相邻场景比较中最大的变化

#### 4.1.3 CAV 渗透率效应

- IDM：渗透率-观测峰值流量曲线呈稳定上升趋势，各场景均在 80%~100% 处达到网格内峰值
- CACC：无瓶颈场景（s1/s2）下随请求渗透率单调上升，高请求渗透率段优势明显（+8.6%~13.6% vs IDM）；瓶颈场景（s3）下 50%~75% 请求渗透率区间出现恶化，全 CAV 时恢复但仍低于 IDM

#### 4.1.4 检测器共振与相变行为

v0.3.0 初期在检测器频率 60s、单圈时间约 60s 的配置下观测到流量周期性波动。将周期改为 120s 后该波动不再出现，因此当前实验使用 120s 统计窗口。在过饱和区（vehN ≥ 100）还观测到流量下降后回升的现象，其形态与闭环交通中的 stop-and-go 至均匀拥堵状态变化一致[11]；现有聚合数据不用于进一步确认该状态转换机制。

### 4.2 安全维度

#### 4.2.1 TTC 冲突分布

| 场景 | 各处理组合的 assignment-seed 平均 TTC 事件数之和 | 全路网 TTC / 1000 普通-edge veh-km 范围 | 特征 |
|---|---|---|---|
| s0 | 1,342,394.0 | 0 ~ 2,500+ | 事件集中于包含 90° 急弯的场景 |
| s1 | 9,109.2 | 0 ~ 200 | 事件数量相对较少 |
| s2 | 0 | 0 | 在当前 SSM 阈值和参数网格下未检出 TTC 冲突 |
| s3 | 1,101,190.2 | 0 ~ 3,500+ | 当前归一化指标数值最高，场景包含强制合流约束 |

第二列先对每个 `scenario × model × requested_pcav × vehN` 组合的五个
assignment-seed 事件数取等权平均，再在场景内跨 504 个组合求和。它表示
“等权平均排列下的场景累计量”，不是 2,520 次 run 的实际事件总和；后者分别
为 s0 6,711,970、s1 45,546、s2 0、s3 5,505,951。

**s0 的 assignment-seed 平均场景累计量（1,342K）超过 s3（1,101K）**。历史 edgeData
未启用 `withInternal`，因此归一化值的分子可能包含 internal edge 上的 SSM
事件，分母则只包含普通 edge 车辆公里。它严格表示“全路网事件 /
普通 edge 的 1,000 vehicle-km”，不能据此判定哪个场景具有最高的完整空间事件率。

#### 4.2.2 TTC 冲突的场景分布

- s0 和 s3 贡献了绝大多数已记录事件，二者分别包含急弯和强制合流约束；
- s1 仅记录少量事件；
- s2 在当前 SSM 阈值、检测范围和参数网格下未检出 TTC 冲突；
- 该分布与几何和拓扑约束的场景差异一致，但不能单独证明具体车辆级作用路径。

这些场景比较支持几何和拓扑约束与 TTC 事件分布密切相关，但不能排除跟驰模型、车辆密度、渗透率及其交互作用。尤其是 s2 的零检出不能解释为所有车辆在所有时刻均不存在低 TTC 状态。

#### 4.2.3 s3 瓶颈中最严重的 TTC 组合

| 模型 | requested pCAV | vehN | TTC 事件 | TTC 事件 / 1000 普通-edge veh-km | 流量 (veh/h) | 相对参考圈时差 (s) | 普通-edge CO₂ (g/veh-km) |
|---|---|---|---|---|---|---|---|
| IDM | 1.00 | 120 | 9,024 | 1,574.0 | 3,204 | 74.2 | 228.3 |
| CACC | 1.00 | 120 | 9,001 | **3,273.5** | **1,536** | **215.8** | **352.0** |
| CACC | 0.95 | 120 | 8,817.8 | 2,837.6 | 1,737.6 | 183.4 | 326.7 |
| IDM | 0.95 | 120 | 8,673 | 1,636.2 | 2,961.6 | 84.8 | 234.6 |

全 CAV、高密度瓶颈条件下，IDM 与 CACC 的 TTC 事件数接近，但 CACC
在统一分析窗口内记录的普通-edge 车辆里程更少。按该暴露量归一化后，CACC
的指标约为 IDM 的 2.08 倍（3,273.5 vs 1,574.0 events/1000 普通-edge
veh-km），同时其流量仅为 1,536 veh/h，而 IDM 为 3,204 veh/h。因此，
**在当前 SSM 阈值、空间口径和该固定运行点下，CACC 的流量与归一化安全
指标均更差**；这不等同于完整空间配对的风险率。

#### 4.2.4 其他安全指标

- **紧急制动**：主要集中在 s3 瓶颈场景（高 vehN 时可达 60 次/run）
- **换道间隙**：所有场景下 `unsafe_lc_gap_count = 0`，表明 LC2013 模型的自身间隙约束在所有实验条件下均被满足
- **DRAC**：与 TTC 分布高度相关，s3 瓶颈中 DRAC 事件数可达 843 次/run

### 4.3 环保维度

#### 4.3.1 CO₂ 排放强度

| 场景 | IDM 典型范围 (g/veh-km) | CACC 典型范围 (g/veh-km) | 趋势 |
|---|---|---|---|
| s0 | 100~300 | 100~300 | 随 vehN 上升而上升 |
| s1 | 80~200 | 80~200 | 低 vehN 时接近自由流，高 vehN 略有上升 |
| s2 | 80~250 | 80~300 | IDM 整体略低于 CACC |
| s3 | 150~350 | 150~**450** | CACC 在瓶颈高密度下排放强度更高 |

#### 4.3.2 CO₂-流量 Trade-off

在所展示的 s3 结果范围内，IDM 通常呈现更有利的 CO₂-流量组合：在相近流量下排放较低，或在相近排放下流量较高。CACC 的高密度排放强度上升与流量下降、相对参考圈时差增大同时出现；是否由更频繁或更强的加减速过程造成，需要车辆级轨迹验证。

在无瓶颈场景（s1/s2）中，两种模型的排放差异相对较小，CO₂ 与流量随车辆数呈现明显变化。现有聚合结果不足以将变化份额严格分解为密度效应和跟驰模型效应。

### 4.4 效率维度

#### 4.4.1 相对参考圈时差（vehN=120）

| 场景 | IDM 参考差范围 | CACC 参考差范围 | 预设参考圈时 |
|---|---|---|---|
| s0 | 18~170s | 18~190s | 98.8s |
| s1 | 0~30s | 0~30s | 60.3s |
| s2 | 0~15s | 0~15s | 60.6s |
| s3 | 50~210s | 50~**250s** | 60.6s |

- s1/s2 在大多数请求渗透率下相对参考圈时差接近零；
- s0 参考差较高，且随 vehN 增加而上升；
- s3 瓶颈的参考差最大：全 CAV 条件下 IDM 为 74.2s，CACC 高达 **215.8s**

#### 4.4.2 效率与容量的关系

s3 中 CACC 的较大相对参考圈时差与低流量同时出现，而 IDM 在相同固定运行点具有较小参考差和更高流量。造成差异的车辆级速度与加减速过程仍需轨迹数据验证。按当前单位车道换算，IDM 全 CAV 条件下 s3 峰值（3,902 veh/h）高于 s2 对应值（3,464 veh/h）；该比较可能受到检测断面、瓶颈排队和车道利用方式影响，不应直接解释为瓶颈提高了单车道效率。

## 5. 综合分析与讨论

### 5.1 跟驰模型的场景依赖性

在当前实验网格和评价指标下，没有一个跟驰模型在所有场景与维度中均占优：

| 场景 | 观测流量更优 | 安全指标更优 | 环保更优 | 效率更优 |
|---|---|---|---|---|
| s1（平滑单车道）| **CACC** | 持平 | 持平 | 持平 |
| s2（平滑双车道）| **CACC** | 持平（均零冲突）| IDM 略优 | 持平 |
| s3（全 CAV、高密度固定运行点）| **IDM** | **IDM** | **IDM** | **IDM** |

CACC 在 s1/s2 中呈现观测流量优势，IDM 则在 s3 全 CAV、高密度固定运行点呈现更有利的多维指标。由于两种模型显式设置的 tau 均为 0.6s，这一差异不是由显式 tau 取值不同造成；但模型类型、SUMO 1.27.1 的模型专属隐式默认参数及其交互并未被进一步隔离，具体机制仍需轨迹级验证。

实验结果呈现出跟驰模型性能与场景约束之间的 trade-off：CACC 在平滑无瓶颈场景中获得更高的网格内观测峰值，而在合流约束下优势减弱或反转。现有聚合指标能够确认这种现象，但不足以证明它由车辆排列紧密程度或某一种控制响应直接造成。

### 5.2 TTC 冲突的场景集中性

在当前实验网格中，TTC 冲突主要集中于具有急弯或合流约束的场景：

- s0 和 s3 贡献了几乎全部已记录 TTC 事件；
- s1 仅记录少量事件，s2 在当前配置下未检出事件；
- 在 s3 全 CAV、高密度运行点，IDM 与 CACC 的 TTC 事件数接近（分别为
  9,024 和 9,001），但当前空间口径下的归一化指标并不接近：CACC 约为 3,273.5
  events/1000 普通-edge veh-km，IDM 约为 1,574.0 events/1000
  普通-edge veh-km

该分布支持几何和拓扑约束与冲突发生密切相关，但不能排除跟驰模型、密度和渗透率的作用，也不能仅凭当前聚合数据确认车辆级因果机制。

### 5.3 多维 trade-off 的完整图景

s2 是无瓶颈多车道的理想基准：CACC 获得测试网格内最高观测流量，IDM 与 CACC 均未检出 TTC 冲突，效率指标大体接近，但 IDM 的 CO₂ 强度整体略低。因此，s2 展示的是 CACC 的观测流量优势，而不是四个维度均占优。

s3 暴露了多目标冲突：在全 CAV、高密度固定运行点，IDM 的流量、普通 edge 排放强度和效率指标均优于 CACC，按普通 edge 里程归一化的 TTC 指标也更低。CACC 在 s2 全 CAV 运行点相对 IDM 的网格内观测峰值优势为 13.6%，而在 s3 全 CAV、高密度运行点，其流量比 IDM 低约 53%。由于安全分子与暴露量空间范围不完全配对，该安全差异只作为当前指标下的运行点观察，不推广为跨场景完整风险率结论。

这一反转不能简单推广为"CACC 不适合瓶颈"。它说明跟驰模型的相对表现具有场景依赖性；至于 IDM 和 CACC 在合流扰动下分别通过何种车辆级响应产生这些聚合结果，仍需结合 THW、加减速度和 FCD 轨迹进一步验证。

---

## 6. 结论

1. **CACC 的观测流量优势是场景依赖的**。在 IDM 与 CACC 均设置 tau=0.6s 的条件下，CACC 在平滑无瓶颈路网中具有更高的网格内观测峰值（s2 全 CAV 达 7,128 veh/h）；但在高密度合流瓶颈下，其流量降至 1,536 veh/h。该差异不能归因于期望车头时距参数，具体机制仍需轨迹级验证。

2. **IDM 在全 CAV、高密度瓶颈运行点呈现更有利的多维结果**。在该固定运行点，IDM 流量约为 CACC 的 2.1 倍，相对参考圈时差约为其 1/3，普通 edge 排放强度更低，按普通 edge 里程归一化的 TTC 指标约为 CACC 的一半。后者不是完整空间配对的事件率；现有结果也不足以将这些差异确定归因于某一种加减速响应机制。

3. **TTC 冲突事件呈现明显的场景集中性**。s0（90° 弯）和 s3（车道收缩）贡献了几乎全部已记录事件，s2 在当前 SSM 配置下未检出 TTC 冲突。该分布与几何和拓扑约束有关，但不足以证明具体车辆级机制，也不能将 s2 的零检出解释为风险被消除。

4. **多维评价体系揭示了单指标无法捕捉的 trade-off**。CACC 在 s2 中取得观测流量优势，且未检出 TTC 冲突，但排放并未优于 IDM；在 s3 全 CAV、高密度运行点，其流量、当前安全指标、排放和效率指标均更差。仅凭流量指标无法区分这两种截然不同的表现。

5. **跟驰模型表现出场景依赖的观测流量—鲁棒性差异**。在当前参数设置下，CACC 在平滑无瓶颈场景中具有更高的网格内观测峰值，而 IDM 在合流瓶颈高密度运行点的多维指标更稳定；这一经验性差异尚不能直接解释为某种既定的车辆级控制机制。

## 7. 局限与展望

### 7.1 当前局限

- **请求与实际 pCAV 不一致**：正式 CSV 的 `pCAV` 表示请求值，CAV 数量则按 `round(vehN × pCAV)` 取整。全网格有 2,400 个 run 的实际值与请求值不同；在 `vehN=10` 时，21 个请求水平折叠为 11 种实际组成，并产生 400 个重复渗透率处理。该问题主要限制低密度渗透率响应的解释，不影响位于 `vehN=60`、80、120 的主要报告运行点。
- **seed 不是独立 SUMO 随机重复**：五个 seed 只改变 CAV/HV 在固定初始位置上的排列；在全 HV 或全 CAV 端点，五个 seed 不会形成五种不同的类型排列。因此五种子波动不能直接解释为独立随机重复下的统计不确定性。
- **HV/CAV 分类未实现**：所有排放和安全指标均为全车队聚合，无法单独评估 CAV 或 HV 子群的行为差异。这限制了"pCAV 提升究竟改变了什么"的归因精度。
- **s2 TTC 为零是当前配置下的结果**：不能推广为"双车道换道完全消除冲突"。TTC 阈值（3.0s）和 SSM 检测范围可能影响该结论的边界。
- **ACC 模型未纳入 v0.4.0**：v0.2.0 曾测试 ACC（tau=1.1s）。将 ACC 纳入瓶颈实验可作为 IDM 与 CACC 之间的补充参照，但更长车头时距是否带来更好的稳定性需要通过受控参数实验验证。
- **自由流基准仅测了 CAV**：建议补 CACC 单车对照以提升相对参考圈时差计算的对称性。
- **兼容字段中的“延误”是有符号参考差**：`mean_lap_delay_s` 与 `p95_lap_delay_s` 是相对
  预设场景参考圈时的差值，可能为负，不应解释为天然非负的经典交通延误。
- **安全暴露量空间范围不完全配对**：SSM 事件未限定为普通 edge，而历史
  performance edgeData 使用 SUMO 默认 `withInternal=false`。现有 raw XML
  无法重建 internal-edge 车辆公里，因此归一化安全值只能解释为“全路网事件 /
  普通 edge 暴露量”；尤其不用于 s0 与其他场景的严格安全率排序。排放分子和
  分母均来自普通 edge，内部配对，但不代表完整环路排放强度。
- **SSM 镜像去重是经验规则**：同一车辆对的反向记录在相遇区间相对较短记录
  重叠至少 80% 时进行一对一合并。SUMO 输出没有可供确定性配对的共享事件 ID；
  密集连续相遇中仍可能误合并或漏合并，因此 TTC 绝对事件数不解释为物理冲突
  的无误差精确计数。
- **P95 方法**：圈时 P95 使用离散 `higher` 分位数
  `ceil((n - 1) × 0.95)`，不使用线性插值。

### 7.2 后续方向

- **v0.4.1**：升级测量链路与实验设计——拆分 HV/CAV 子群指标，引入
  physical THW 和紧凑 FCD/TraCI 验证，执行 TTC 阈值敏感性分析，统一
  internal-edge 安全暴露量，分离车辆类型排列 seed 与独立 SUMO 随机重复，
  补齐 IDM/CACC 分模型自由流参考；先以有界 pilot 验证正确性、存储量和运行
  成本，不把 10,080 次完整重跑作为默认交付物
- **v0.4.2（条件性）**：仅当 v0.4.1 pilot 通过预定义门禁且确有研究必要时，
  使用新实验设计运行正式网格并发布新的版本化数据；不得覆盖 v0.4.0/post3
  > 更新（2026-07-31 后）：该条件已被当前方向取代——v0.4.2 直接按 A 线执行，
  > 资源表现不构成发布否决权。
- **v0.5.0**：真实轨迹驱动的跟驰模型标定与仿真验证
- **v0.6.0**：引入 TraCI 接口实现动态车速引导与匝道汇入控制
- **v0.7.0**：对 CACC 的通信能力进行参数化降级（丢包率、延迟、通信范围衰减），模拟真实 V2V 环境干扰
